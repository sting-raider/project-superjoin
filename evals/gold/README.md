# Source-verified evaluation records

Gold records use JSONL so each claim or relationship can carry its own source
hash, PDF page, printed page, evidence text, geometry, qualifiers, and
annotation rationale. The initial repository ships the schema and controlled
security fixtures; source-derived annotations are prepared locally after the
redistribution audit permits their publication.

Do not treat the recorded demo snapshot as a gold set. Gold labels are held out
from extraction and are split by fact family to avoid leakage.
